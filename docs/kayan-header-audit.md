# تدقيق قالب كيان + سبب الهيدر المكسور

**الموقع:** https://www.rukn-eltatawer.com/om  
**القالب:** Kayan Theme + طبقة CSS للهوم بيج (`#hdr`)  
**التاريخ:** 23 سبتمبر 2026

## لماذا يظهر الهيدر مكسورًا؟

السبب ليس شعارًا تالفًا. السبب قاعدة CSS في إضافة `rukn-oman-seo` حُقنت لإظهار القائمة الفارغة سابقًا:

```css
nav.menu{display:flex;flex-wrap:wrap}
nav.menu a{color:inherit}
```

هذه القاعدة **أقوى** من قاعدة القالب عند العرض الضيق:

```css
@media(max-width:768px){
  .menu, .nav-cta > a.btn { display:none }
}
```

`.menu { display:none }` خصوصيتها أقل من `nav.menu { display:flex }`، فالقائمة لا تُخفى على الموبايل. مع `flex-wrap:wrap` وارتفاع هيدر ثابت 80px، الروابط السبعة (رئيسية، خدماتنا، المدن، من نحن، الأسئلة، واتساب، خريطة الموقع) تنزل سطرًا ثانيًا **فوق الشعار ونص الهيرو**.

ما يظهر على الشاشة:

| العرض | ماذا يحدث |
|---|---|
| 1440px | صف واحد؛ يبدو مقبولًا |
| ~1100px | سطران: «واتساب» و«خريطة الموقع» ينزلان تحت القائمة ويتداخلان مع الشعار |
| 390px | الهامبرغر يظهر، لكن روابط القائمة تبقى ظاهرة وتتراكب على الشعار والنص |

قائمة الموبايل `#ruknMob` كانت **بدون روابط** (بحث + لغة + واتساب فقط). CSS كان جاهزًا لـ `.rukn-mob-links` لكن HTML لم يُحقَن في النسخة المخزَّنة من LiteSpeed.

الشعار نفسه ملف كاميرا `IMG_٢٠٢٦٠٩١٧_٠٢١٠٢٤.webp` (كلمة «ركن التطور» ثلاثية الأبعاد) وليس `logo-icon.webp`. على الخلفية الزرقاء يظهر بحد أسود خشن.

## بقايا الإمارات

واتساب `971586634710` **مقصود** (طلب سابق: لا تغيّر الرقم إلى +968). الباقي أدناه بقايا قالب/إعدادات كيان للنسخة الإماراتية:

| البقايا | أين | الأثر |
|---|---|---|
| `currency: "AED"` | `KayanPricePay` و`KayanBookingConfig` و`data-currency="AED"` في باقات الأسعار | الدفع/الواجهة تعلن درهمًا رغم أن النص يقول ريال عُماني |
| `telephone: "+971586634710"` في Schema | JSON-LD LocalBusiness | متوافق مع واتساب الحالي؛ ليس خطأ تنقل |
| `"priceRange":"OMR",}` | JSON-LD فيه فاصلة زائدة | JSON غير صالح |
| كلاس `.uae-svg` في CSS | ستايل خريطة التغطية | HTML صار `oman-svg` لكن الاسم الإماراتي باقٍ في CSS |
| 18 أيقونة من النطاق الأب | `rukn-eltatawer.com/wp-content/uploads/icon/...` بدون `/om/` | الملفات تعمل من موقع الإمارات؛ المسار نفسه بقايا |
| `Search Now` | `data-searching-argums` في زر البحث | واجهة البحث بالإنجليزية |
| `taxRate: "5"` + أيام الحجز | إعدادات كيان للحجز | ضريبة/جدول من نسخة الخليج؛ يحتاج مراجعة تشغيلية |
| `link rel="preload" as="font"` بلا `href` | `</head>` | preload غير صالح |

لا توجد كلمات دبي / أبوظبي / الشارقة / درهم في HTML الصفحة الرئيسية الحالي.

## نواقص أخرى في القالب

- CSS كيان الأصلي ما زال يُحمَّل كاملًا (`header{left:0}`، `body.hidemenu`، `.--Site--Menu`) فوق هيدر الهوم كيت فيتعارضان.
- `<link rel="stylesheet">` للقالب شبه غائب؛ جزء كبير inline. extra Kayan CSS يضخّم الصفحة.
- عنصر `<root>` غير قياسي يلف الصفحة.
- `#loader` يغطي الشاشة 0.35–1.8 ثانية؛ إن تعطّل JS يبقى كحاجز كحلي.
- عدّادات الهيرو تتحرك من 0 (لقطة الشاشة أظهرت 15 خدمة / 7 مدن أثناء العدّ، والقيمة النهائية 16/8).
- على المقالات: `tel:` واحد ما زال في المصدر رغم إخفاء أزرار الاتصال بالـ CSS.

## ما الذي أُصلح في 2.0.3

- إخفاء `header#hdr nav.menu` تحت 1200px بـ `!important` وإظهار الهامبرغر.
- منع الالتفاف: `flex-wrap:nowrap`.
- لون الروابط أبيض على الهيدر الشفاف، كحلي بعد `.scrolled`.
- تقليص عناصر الـ nav إلى 5 (واتساب يبقى زر CTA، الخريطة في التذييل/موبايل).
- حقن `.rukn-mob-links` في درج الموبايل + نسخة JS احتياطية.
- استبدال `AED` الظاهر في JSON الواجهة بـ `OMR`.
